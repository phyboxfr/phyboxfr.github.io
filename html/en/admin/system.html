System


The PhYBoX is structured into different modules which ensure each of its functionalities. In the main folder are the 4 folders at the base of this System :


Server :

main folder which contains the components of the BoX, Library and Collaborative Board servers

Web :

BoX interface and its applications, made up of the following components :


Login : portal and student identification panel by password
Explorer : Files explorer
Index : indexing engine for student documents
Ext : applications necessary to read the different document formats depending on their extension
App : applications appearing in the app gallery
Proxy : manages the BoX proxy, in order to limit Internet access only to sites authorized by the teacher
Tools : tools ensuring various general functionalities used by applications (message, format conversion, printing, PDF, OCR, QR code etc.)


Doc :

it is in this folder that you can put the documents intended for students which will be visible in the explorer. It is necessary to create a folder for each level (Year 7,8,9 etc.)

Classes :

folder where everything relating to classes is located, in particular the list of students with their password and where all their productions are recorded


Important Note :

The BoX is a portable application, so its folder can be unzipped anywhere, but the names of the folders containing it must not contain an accent, otherwise the server will not be able to start :

[ C:\My folder\Phybox ]
