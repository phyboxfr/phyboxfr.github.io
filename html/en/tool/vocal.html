Vocal


This application for the administrator records the voice of the Speech Synthesis which is made to read a given text.

The teacher can thus offer the student an audio version of a document, letting them choose the one that would be most suitable for them. This can be particularly useful with the image of the screenshot of a website page, for which real time Text-to-Speech is not possible.

The audio file is saved in ogg format in the folder :

[phybox]  ->  [doc]  ->  [download]

Note :   This file can be listened to directly from the BoX explorer, but to make it visible to the search engine, remember to index it by updating the documents in the startup console.
