Indexation


Afin de rendre l'accès aux documents plus efficace, ils sont indexés dans la base de données du serveur. Diverses informations sont enregistrés tel que le nom des fichiers, leur emplacement sur le disque, leur type etc.

Le moteur de recherche et les liens courts utilisent ainsi l'indexation pour retrouver rapidement un fichier à l'aide de mots clés. L'indexation des documents est donc nécessaire avant qu'ils ne soient disponibles dans la BoX et que les élèves puissent les voir.


Comment Indexer les Documents Élèves ? :

Par défaut, la mise à jour de l'indexation est lancée automatiquement au démarrage de la BoX afin d'y intégrer d'éventuels nouveaux documents que vous auriez ajoutés.

Cependant, si vous avez beaucoup de documents, l'indexation peut prendre davantage de temps. Dans ce cas, vous pouvez désactiver la mise à jour automatique dans le panneau de configuration, afin d'éviter qu'elle ne ralentisse le fonctionnement de la BoX :


Et quand vous n'utilisez plus la BoX avec vos élèves, vous pouvez lancer la mise à jour en cliquant sur le bouton Update de la console :

Cliquez sur Update ou Reset


Update : lance la mise à jour de l'indexation
Reset : efface puis recommence l'indexation

Remarque :

Au moment de l'indexation des images et des vidéos, une miniature est capturée. Les miniatures servent d'illustration dans la liste de lecture du lecteur vidéo et dans l'explorateur. Les vidéos ne sont donc visibles dans le lecteur vidéo que si elles ont d'abord été indexées. Elles sont enregistrées dans le dossier :
