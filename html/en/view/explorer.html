➀   The Search Engine does not take into account accents and capital letters to simplify its use and accepts several keywords simultaneously, in order to clarify its request. The results returned are limited to those at the student's level. For example, a CE1 student cannot see documents intended for CM2 students. In the selector on the left, you can choose the type of document you want (text, image, video, etc.).

➃   Folder containing the items that students have set as Favorites to access them more quickly. Any folder or document can be placed in Favorites, simply by clicking at the end of its line. A star will then appear to indicate it and simply click on it again to delete it.

➄   The purple separator bar can be moved to give more or less space to the Folder Tree panel as needed.


Notes :

Read Only :

All documents placed by the teacher in the file [doc] are read-only and therefore cannot be modified by students. This is the reason why the students' productions go into the [classes] folder, in which they can freely modify them.

Hidden Folder :

If you name a folder [coffre] in french or [safe] in english, it will not be displayed in the BoX Explorer. You can therefore store files there temporarily so that they are not visible to students (a quiz for example) and remove them when necessary.



The Actions :

Some file types may have additional buttons at the end of the line to perform specific actions :



Text : Pressing the Edit button allows you to make a copy in the student's file of the file (odt, docx) which serves as a writing model (e.g. a Practical Work sheet to guide the student's procedure), then opens it in the Editor so that he can complete it. The student therefore only modifies his version of the document in his file and not the teacher's document, which remains read-only.
Image : Copy the image to the clipboard (to paste it into the text editor).
Video : Specific use for Sciences, the Edit button opens the video of a moving object in the Tracker application, in order to highlight its trajectory (the button appears if the video has been put in a folder whose name begins with the symbol @).
Quiz : Edit the quiz to modify it, Play to launch the server which allows students to play together (otherwise everyone plays individually), Stat displays the statistics of each student who has already played individually.
