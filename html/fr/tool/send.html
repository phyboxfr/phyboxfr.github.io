Envoi


Cette application permet à un élève d'envoyer n'importe quel document présent sur la tablette, jusqu'à son dossier nominatif sur l'ordinateur de l'enseignant.

Ainsi, un document créé par une application de la BoX est automatiquement enregiostré dans le dossier de l'élève. Mais s'il a été conçu dans une autre application installée sur la Tablette ou depuis un site internet, il peut également l'envoyer vers l'ordinateur du professeur.
