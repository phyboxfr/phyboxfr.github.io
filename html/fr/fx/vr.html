VR


La PhYBoX intègre des applications pour visualiser des images et des vidéos en Réalité Virtuelle. Ces technologies permettent une meilleure immersion dans les documents, ce qui les rend plus attractifs :


PANORAMA à 360° :

La PhYBoX intègre l'application : Photo Sphere Viewer



Utilisation : Pour qu'une image prise en 360° soit présentée dans ce lecteur panoramique, il suffit simplement de la placer n'importe où dans les documents élèves comme n'importe quelle autre image, mais dans un dossier nommé [VR]. Vous en trouverez un exemple dans le dossier [exemples] :

[phybox]  ->  [doc]  ->  [exemples]  ->  [VR]


VIDÉO VR 360° :

La PhYBoX intègre l'application : Videojs-Panorama



Si vous disposez d'un casque VR, vous pouvez connecter votre téléphone portable à la PhYBoX afin de regarder la vidéo en activant le mode VR pour une immersion complète.

Sur l'écran s'affiche 3 commandes de lecture en tête haute, que l'on peut valider en restant le regard positionné dessus pendant 3 secondes. Cela permet de naviguer parmi les vidéos sans avoir à enlever le casque.

Utilisation : Comme pour les images, les vidéos en VR sont envoyées dans le lecteur VR plutôt qure dans le lecteur vidéo classique, simplement en les déposant dans un dossier nommé [VR]. Vous n'avez donc rien à faire, la PhYBoX s'occupe de tout. Vous en trouverez un exemple dans le dossier [exemples] :

[phybox]  ->  [doc]  ->  [exemples]  ->  [VR]


Aspect technique :     Complément facultatif, pour ceux qui souhaiteraient aller plus loin dans l'usage de la VR en classe.

Par défaut, ce lecteur lit les vidéos VR en 2D encodées dans la projection la plus courante dite équirectangulaire (c'est celle qui est utilisée pour les planisphères en géographie).

Cependant, le lecteur VR de la PhYBoX lit aussi d'autres formats de VR (180° et 360°) en 2D et en 3D équirectangulaire. Pour cela, il suffit d'ajouter dans son nom un identifiant reconnu par le lecteur :

2D nom
3D 360° Haut/Bas nom + 3D360
3D 360° Gauche/Droite nom + 3D360LR
3D 180° Gauche/Droite nom + 3D180

video.mp4   ->   video3D360LR.mp4

Remarque sur la Projection EAC :

Certaines vidéos VR sur Youtube n'utilisent pas la projection équirectangulaire, mais une projection créée par Google nommée Equi-Angular Cubemap (EAC). Ceci, afin de corriger le défaut majeur de la projection équirectangulaire qui donne davantage de résolution aux extrémités qu'au centre de l'image, où se trouve pourtant souvent l'essentiel de l'action.

Cette projection permet de mieux répartir la résolution de l'image (donc la netteté) sur l'ensemble des zones. Cela se traduit par l'ajout d'une 2ème bande vidéo qui est centrée sur le milieu de l'image afin de lui redonner plus de définition.

Lorsque l'on regarde ce type de vidéo dans le lecteur de Youtube qui sait gérer cette projection, on ne la voit pas puisqu'elle est intégrée dans la vue présentée par le lecteur. Par contre, si vous la téléchargez pour la regarder sur votre ordinateur avec un lecteur comme VLC, la vidéo apparait coupée en deux bandes horizontales différentes (voir 4 pour de la 3D). Le lecteur de la PhYBox ne prend pas en charge l'EAC.

Un logiciel gratuit qui lit tous les formats de VR (y compris l'EAC) : PotPlayer
