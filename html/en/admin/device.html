After launching PhYBoX on the computer, you can now connect the Tablets. .

You must first connect your devices to the Router's Wifi, then go to the browser and copy the address displayed by the PhYBoX console.

To go faster, the PhYBoX can generate a QR Code, which allows you to both create the Wifi connection and launch the browser to go to the PhYBoX Address, if the Android version of the Tablet allows it :

Generate a QR Code for students




Wifi : The Name of the Wifi Network
Key : The Wifi Network Password
Link : The PhYBoX Address

Subsequently, to avoid students having to type the address each time, you can put a shortcut on the desktop of each tablet. You will find this feature named “Add to Home Screen” in the browser menu.

However, this assumes that the IP address of your computer remains fixed, so you must also make an address reservation in the application that allows you to manage your Router. It is not possible to give a general guideline on this subject, since each Router model is different, so you will need to refer to its manual.


Note :

If you want students to also be able to connect with their smartphone (for example to use a VR headset), it is better to create a second independent access, as Routers often offer the possibility of launching a network for Guests.

On the latter, you can choose a simple Password (123..) to communicate to the students and which you can easily change if necessary, without having to change the Network password for the Tablets.
