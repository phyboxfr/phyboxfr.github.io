Features

The Box is Multilingual :

In the hope that as many people as possible will find this application useful, you may choose a different language to the original French.

The initial version is available in four languages ​​(German, English, Spanish, French), and I am grateful to colleagues from the relevant disciplines who have contributed their skills to the translation of this application.

For the rest, the dedicated section in the forum allows users to suggest a translation in their language. The language files are located in the following folder :

Peace of Work in a Local Network :

The different functionalities offered by the PhYBoX are independent of the Internet and run independently on the teacher's computer, in the local network created by the router within the class.

The objective being that most of the resources are available in the class, without having to go through the school's network or the Internet. Therefore, there is no need to worry if, for whatever reason, the school's internet connection is cut off.

This also allows the teacher to work with peace of mind, knowing that students only have access to the selected documents without having to worry about the distractions they might encounter while freely browsing the internet.

It is thus possible to consult Wikipedia and other content of the same type, which are stored directly on the computer without having to go through the Internet.

The use of websites can therefore be limited to a few essential educational sites when equivalent content cannot be found in the local settup. for which it would not have been possible to find equivalent content in local operation.

For this, PhYBoX offers its own internet connection filtering system, which allows you to only authorize the sites you have chosen, all others being blocked by default. See the Admin -> Internet section for a detailed description of this system.


Autonomy, Differentiation and Adaptations :

One of the main aspects of this type of system is to facilitate the implementation of activities where students work independently, by allowing differentiation and proposing adaptations for the specific needs of each student.

First of all, by having different versions of the documents, with varying levels of reading and comprehension, we give the student the opportunity to invest to their extent in the proposed work, by choosing for themselves those that suit them most. This avoids having to print different versions on paper.

This also makes it possible to put optional additional documents in a separate folder, for the most committed students who would have the time to explore this work even further.

Furthermore, in order to facilitate use for students experiencing some problems with writing, PhYBoX uses synthesis and voice recognition integrated into the browser. This means that part of the work proposed to students can be transmitted and carried out orally rather than in writing.

The PhYBoX is thus structured so that the starting point for the students' work can be an activity sheet in PDF format presenting the instructions. The PDF reader allows a certain number of technical adjustments which are fully integrated in the spirit in which this box was designed.

The student can already adjust the size of the text as desired to make it more readable, with the usual two-finger touch gesture. But if that's not enough, just by tapping on any sentence, it will be read by text-to-speech.

De façon plus générale, la présence du bouton que l'on trouve à plusieurs endroits de la BoX, indique que le message affiché peut être lu par la Synthèse Vocale.

On the other hand, when students are asked to analyze an image, part of which contains text, the latter can also be selected and read using a character recognition tool.. See the Documents -> Image section for a detailed description of this function.

It is also possible to create a voice-dictated text document with a few specific voice commands. The produced document is then saved in the student's file (in odt or docx format) automatically. Refer to the Applications - Editor section for a detailed description of this function.


Short links :

PDF files also recognize a system of shortcut links to click to send the student directly to the appropriate documents, rather than writing a long instruction to tell them to go to such and such place or see such and such document.

This system allows you to reference a file or folder in the simplest way possible, without making this document management too restrictive for the teacher, but you have to try it yourself to fully understand the benifits.

This pdf activity sheet is therefore the simplest access point for students, to prevent them from getting lost among the documents that you have prepared for them. You will find a detailed description of this important function in the Documents -> Pdf section of this site, as well as an example of use in the following folder in the box :

[phybox]  ->  [doc]  ->  [6ème]  ->  Example of links.pdf


Student Identification :

The list of classes with the names of the students is imported into the box from an excel file (ods, xlsx). Student passwords can be generated either automatically upon their first connection, chosen from a list of predefined words or even randomly.

During the session, the teacher can also monitor the list of connected students on each tablet. This will make it possible, for example, to identify which student used which tablet on a given date.

All password management functions are described in the Admin -> Password section.


Documents Indexing :

In order to access documents more quickly, the box indexes them in its database. It is on this operation that the short links and the search engine are based. Visit the Admin -> Indexing section for a detailed description of this function.


Student Productions :

Student productions are automatically saved in a folder in their name on the teacher's computer. At the end of the sequence, all that remains is to copy the class folder onto your USB key, to correct them later.
