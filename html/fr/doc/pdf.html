Pdf


La PhYBoX intègre l'application : Pdf.js

Développée par la Fondation Mozilla, cette application est utilisée dans le navigateur Firefox pour ouvrir les documents pdf.

Dans la PhYBoX, ces fichiers sont utilisés pour proposer une version numérique et dynamique de la fiche d'activité des élèves, qui est un des éléments centraux du dispositif. Elle sert ainsi de poste d'aiguillage pour l'accès aux documents d'accompagnement.

Plusieurs fonctionnalités sont ainsi ajoutées à l'ouverture des documents pdf, afin de les adapter à l'environnement de la BoX :

Lecture :

En cliquant sur une ligne, le texte est prononcé par la synthèse vocale pour aider les élèves ayant des difficultés de lecture.

Pour que cela soit possible, il faut que le fichier pdf contienne des repères de structure. Au moment d'enregistrer votre fichier au format pdf depuis votre traitement de texte, vérifier dans les options du format pdf que la case des repères (étiquettes) est bien cochée.

Dans Libre Office : « Exporter les repères de texte » et dans Microsoft Office : « Étiquettes de structure de document pour l’accessibilité » :

Lien :

Il est possible d'ajouter des liens directs vers des documents mis à la disposition des élèves dans le dossier [doc].

C'est la façon la plus simple pour permettre aux élèves d'accéder aux documents, plutôt que de passer par l'arborescence des dossiers dans l'explorateur.

Ainsi, dans la version numérique de la fiche d'activité en pdf, on ajoute à côté de la question posée un lien sous la forme d'un texte ou d'une image. L'élève n'a plus qu'à cliquer sur ce lien pour découvrir les documents qui vont l'aider à répondre à la question.

Une syntaxe spécifique permet de choisir si le document doit s'ouvrir dans le lecteur image, vidéo, audio, l'explorateur etc. Par exemple, dans votre traitement de texte, au lieu d'écrire un lien sous la forme d'une adresse classique vers un site internet, on met :

http://www.site.com   ⟶   dir:chemin/vers/le/dossier
document : doc
dossier : dir
image : img
vidéo : vid
audio : aud
site : web

D'autre part, pour simplifier l'écriture du chemin vers le dossier qui peut être fastidieuse, on peut utiliser une écriture raccourcie en ne gardant qu'une partie de chaque élément du chemin (du moment qu'il soit unique) :

[doc] / 6ème / Français / Chapitre 2 / Conjugaison   ⟶   dir:6/f/2/c

Le chemin peut être celui d'un dossier ou d'un fichier. Si c'est un dossier, l'ensemble des fichiers du dossier sont affichés dans le lecteur et si c'est un fichier, le lecteur démarre sur celui-ci :

vid:6/f/2/c/vidéo.mp4

Lorsque l'on clique sur ce lien, ce média se lancera dans le lecteur vidéo.

Vous trouverez un exemple de fichier pdf avec des liens de ce type dans le dossier [doc] :

[phybox]  ->  [doc]  ->  [6ème]  ->  Example of links.pdf
