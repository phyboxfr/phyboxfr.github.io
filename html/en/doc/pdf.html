Pdf


The PhYBoX integrates the application : Pdf.js

Developed by the Fondation Mozilla, this application is used in the Firefox browser to open pdf documents.

In the BoX, these files are used to offer a digital and dynamic version of the student activity sheet, which is one of the central elements of the system. It thus serves as a referral point for access to accompanying documents.

To do this, several features have been added to adapt it to the PhYBoX environment :

Reading :

By clicking on a line, the text is spoken using voice synthesis to help students with reading difficulties.

For this to be possible, the pdf file must contain structural markers. When saving your file in PDF format from your word processor, check in the PDF format options that the markers (labels) box is checked.

In Libre Office : « Export text marks » and in Microsoft Office : « Document structure labels for accessibility » :

Link :

It is possible to add direct links to documents made available to students in the [doc] folder.

This is the simplest way to allow students to access documents, rather than going through the folder tree in Explorer.

Thus, in the digital version of the activity sheet in PDF, we add next to the question asked a link in the form of a text or an image. All the student has to do is click on this link to discover the documents that will help them answer the question.

A specific syntax allows you to choose whether the document should open in the image, video, audio player, explorer, etc. For example, in your word processor, instead of writing a link in the form of a classic address to a website, we put :

http://www.site.com   ⟶   dir:chemin/vers/le/dossier
document : doc
dossier : dir
image : img
vidéo : vid
audio : aud
site : web

On the other hand, to simplify writing the path to the folder which can be tedious, we can use shortened writing by keeping only part of each element of the path (as long as it is unique) :

[doc] / 6ème / French / Chapter 2 / Conjugation   ⟶   dir:6/f/2/c

The path can be that of a folder or a file. If it is a folder, all the files in the folder are displayed in the player and if it is a file, the player starts on it :

vid:6/f/2/c/video.mp4

When we click on this link, this media will launch in the video player.

You will find an example pdf file with links of this type in the [doc] folder :

[phybox]  ->  [doc]  ->  [6ème]  ->  Example of links.pdf
