Adaptation


The PhYBoX offers two tools to help students who encounter certain reading difficulties :


Use of the OpenDyslexic font in Explorer, Kiwix Libraries and documents in txt, html format.



Use of Voice Synthesis to read the documents provided to students :

On documents in txt, odt, html, pdf format and all Kiwix Libraries, simply touch one of the texts on the page for the entire paragraph to be read by the tablet.

An icon on the login panel allows you to disable this feature for students for whom it is not required, in order to prevent it from being triggered unnecessarily.

On compatible browsers such as Firefox, reading can also be accompanied by highlighting of the word being read.

For Android tablets, this feature is not available with browsers based on the Chromium project (Chrome, Brave, Opera, etc.) which do not currently allow it.

If this feature can be useful to your students, then it is recommended to use the Firefox browser for Android which offers it : Firefox Android
