WHAT MATERIALS DO YOU NEED ?

A computer and a WiFi router, that’s it !

     .. That seems rather complicated to me ?!

Not at all! No need to worry, there is hardly any need for technical knowledge to operate this device. Simply plug them together, launch the application which takes care of everything for you and off you go for the educational adventure.


The Computer :

This device was developed only for Windows systems. Furthermore, it is recommended that the computer be equipped with an SSD disk rather than a hard disk, in order to increase the rate of data exchanged with the devices that connect to it.


The Browser :

The PhYBoX is not an application in itself, but it opens in your browser as if it were a website. However, it is optimized for browsers based on Chromium (Chrome, Brave, Opera etc.), certain features may therefore present display bugs with other browsers.


The Router :

You may already be using a router without knowing it, since your internet operator's BoX contains one. This is what produces the Wifi network to which you connect your various devices so that they have access to the internet.

So you can simply start trying PhYBoX at home to familiarize yourself with its features, before using it in class with a dedicated router. In this case, simply launch the application on a computer connected to your home WiFi and enter the application's address shown on its interface, into the browser.

One of the advantages of using the browser is that PhYBoX is thus accessible from any device connected to the same network (computer, tablet, smartphone), without having to install an application on each device. It couldn't be simpler !

In class, the Router will similarly allow the teacher's computer to be connected with the students' tablets or smartphones in a local network. We could use the computer's WiFi card, but its often limited performance risks penalizing its use. It is therefore better to use a dedicated WiFi router, which is connected to the computer, preferably with a network cable.

Which one to choose ?

The current performance of mid-range routers can ensure a sufficient number of simultaneous connections, but it is better to choose a router with several antennas.

Tip :

Rather than a flat model with many antennas sticking out everywhere, some have a cylindrical shape and internal antennas, which makes them more practical to install on the teacher's desk, which is often already very cluttered. But this remains a matter of personal choice.
