AR


The PhYBoX integrates the application : AR.js

This application allows you to add Augmented Reality to your documents by inserting markers that work like QRCodes and that the application can recognize. You will find an example in Chemistry in the file :

[phybox]  ->  [doc]  ->  [exemples]  ->  [AR]

Once you have written a document in your word processor with a few markers, save it with the other student documents in .pdf format and in a folder named [AR].

So, when the user clicks on this file, PhYBoX opens the augmented reality player and turns on the webcam. By presenting the printed version of the document in front of the webcam, the markers will be replaced by the 3D models you have chosen..

In the folder [phybox] -> [asset] -> [app] -> [AR] vyou will find the images of each marker to insert into your word processor. Each marker is numbered and it is this number which is used to identify it to replace it with the 3D model which bears the same number.

Your 3D models must be placed in the pdf document folder, in a subfolder of the same name as your document: :

[phybox]  ->  [doc]  ->  [4ème]  ->  [AR]  ->  [nom du fichier pdf]  ->  3.glb

So, when you click on a pdf file that contains AR markers, PhYBoX will replace each marker with the 3D model of the same number and which is located in the folder of the same name as the pdf document. This is the method that was chosen to associate each marker with the correct model, in order to avoid the teacher having to write code.

3D models must be in .glb format, but free sites are easily found to convert one of the many 3D model formats (.stl, .3ds, .blender etc.) to glb. GLB is a format for the web which has the advantage of including the model textures in a single file.

A free 3D model site among others : Archive3D
