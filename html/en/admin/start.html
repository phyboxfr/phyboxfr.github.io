Start


To start the PhYBoX, go to its main folder and click on the application phybox.exe.

Windows may then display a warning message from its "Microsoft Defender SmartScreen" protection feature :


This protection can be triggered when launching a downloaded application that is little known or does not have a digital signature allowing the publisher to be identified, which is the case with PhYBoX.
