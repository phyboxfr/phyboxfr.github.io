Security


When starting the Browser, you will see the following message appear on Chrome, or an equivalent message on other browsers :



No need to worry, this is the expected behavior of the Browser.

Indeed, the PhYBoX site operates in secure https mode (normally indicated by a small padlock in the address bar). However, for this to be possible on a local site which is not known to the Browser, an exception must be generated which authorizes this site to be consulted in https mode (rather than http).

The Browser therefore informs the user by asking for their authorization, in order to verify that they wish to consult this site with full knowledge of the facts.

As the BoX runs in a local network (it is not on the internet), this situation does not present any security problem and you can therefore validate the exception by clicking on « Advanced Settings » then « Continue to the site » :



This message will return periodically since the authorization granted by the user will be renewed regularly by the Browser.


Note :

From the start of using PhYBoX with your students, it is therefore important to explain to them what they should do when they see this message.
