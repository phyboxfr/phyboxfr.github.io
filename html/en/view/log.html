     The Connections Reader allows the Administrator to have an overview of the use of BoX, by recording student connections on each mobile classroom device (PC, tablets, smartphones) for a week :


Screen: Total number of devices that have already connected at least once.
Connected : Number of devices currently connected.
Disconnected : Number of unused devices.

➀   By default, the list is put in the order of Screen numbers. But by clicking on one of the other headers (Screens, Names, Class, etc.), the list is put in the order of the chosen element. For example, if you are looking for a particular student, click on the column Names to put the list in alphabetical order of Names and find it more quickly.

➁   The Connections Viewer opens showing only the devices that have students in the class you are currently working with connected to. This button allows you to change class in order to see the use of devices with another class, or even all.

➂   The box turns green when the student logs in and orange when they log out. In the history only these two moments are recorded.


This Viewer's page is refreshed regularly to update the list of connections. If you just want to view the list without it constantly being re-initialized, use the switch at the top right to stop updating.


Note :

Devices (Screens) are identified by their MAC address, which is recorded in the Server database when it connects to it for the first time. It is therefore important when you configure the device's WiFi connection to select the option allowing you to keep the Real MAC address of the Tablet rather than a Random value. >, who would have no interest in this situation :
