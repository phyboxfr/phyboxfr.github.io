Capture


This application is a tool for the administrator that allows you to download a page from a website into a single file containing all the elements necessary for its reading, including images.

This will make it possible to consult this page locally without needing the internet, building up a library of documents that are permanently accessible. This also allows the BoX to add the use of Voice Synthesis.

However, the accuracy of the replica of this page can only be assured for sites whose structure remains relatively simple.



The page is saved in its original format in the folder :

[phybox]  ->  [doc]  ->  [download]

An option allows you to simultaneously save the secondary pages whose links are present in this document. They are then grouped in a subfolder for greater simplicity. Thus, from the main page, if you click on one of these links, the BoX can find these pages.


Capture is based on the application : Obelisk
