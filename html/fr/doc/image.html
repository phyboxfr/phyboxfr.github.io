La PhYBoX intègre l'application : PhotoSwipe

Tous les formats d'image s'ouvrent avec Photoswipe, afin de retrouver dans le navigateur la fluidité qu'offrent les galeries d'images sur les écrans tactiles. On passe d'une image à l'autre en les faisant glisser et on zoome dessus avec le geste de pinch usuel.

Dans le coin supérieur droit se trouve une petite barre d'outils pour lui ajouter quelques fonctionnalités :

   Retourne dans l'explorateur, au dossier d'où sont issus les images.

   Adaptation pour les élèves rencontrant des soucis de lecture, en utilisant la synthèse vocale pour énoncer un texte contenu dans une image. Un cadre bleu permet de sélectionner une partie de l'image où se trouve le texte et en double cliquant dessus, un outil de reconnaissance de caractère lit le texte avec la synthèse vocale.

Moteur de reconnaissance de caractère ocr : Tesseract.js
