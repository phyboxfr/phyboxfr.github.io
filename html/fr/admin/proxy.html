Internet   &   Proxy


Le Proxy de la BoX :



1) C'est quoi un PROXY ? :

Dans les établissements scolaires, toutes les connexions Internet sont renvoyées vers un serveur central nommé Proxy (mandataire en Français). Il sert notamment à filtrer les demandes de connexion, en autorisant uniquement l'accès à des sites d'intérêt pédagogique, puis c'est lui qui fait à votre place les requêtes auprès des sites demandés et vous les renvoie.

Afin que cela soit possible, l'ordinateur de votre salle (tout comme les classes mobiles) a certainement été configuré par le service informatique dont vous dépendez pour renvoyer ses requêtes vers ce mandataire, identifié par son adresse qui est usuellement : IP = 172.16.0.1 et port = 3128.

Si vous regardez dans les paramètres de Windows ou du Navigateur, en cherchant avec le mot clé proxy, vous devriez trouver l'adresse du Proxy de votre établissement :

Cliquer sur Démarrer   ->   Paramètres   ->   Réseau et internet   ->   Proxy


2) Le PROXY de la PhYBoX :

L'un des principes directeurs de ce type de BoX est de faire travailler les élèves dans un réseau local, avec la sécurité de savoir que les élèves ont uniquement accès aux documents et applications sélectionnés par l'enseignant.

Afin d'éviter les inévitables distractions qui pourraient survenir en laissant les élèves naviguer librement, l'usage de sites internet doit donc être limité à quelques sites pédagogiques indispensables, pour lesquels il n'aurait pas été possible de trouver un contenu équivalent dans un fonctionnement en local.

Pour permettre ce mode de fonctionnement, la BoX possède son propre Proxy qui filtre les connexions par le biais d'une liste de sites autorisés, que vous pouvez choisir dans son panneau de configuration.

Lorsqu'il est activé, ce filtrage se rajoute à celui de l'établissement, afin que seuls les sites que vous avez mis en liste blanche soient autorisés et tous les autres bloqués :



3) Configuration de la Connexion WIFI :

Pour pouvoir utiliser le Proxy de la BoX, quand vous connectez une Tablette sur le Wifi du Routeur, il faut rediriger la connexion vers le Proxy de la BoX plutôt que vers celui de l'établissement. C'est la BoX qui se chargera par la suite de renvoyer cette connexion vers le Proxy de votre établissement.

Par exemple, pour les tablettes sous Android, dans les paramètres de la connexion Wifi, il faut choisir les paramètres du Proxy de la façon suivante :



Paramètres de la connexion Wifi   -->   Paramètres avancés :

Proxy :   manuel

Nom de l'hôte proxy :   l'adresse IP de la Phybox (qui est marquée sur la console de démarrage, par exemple: 192.168.0.100)

Port du Proxy :   3128

Contourner le proxy pour :   l'adresse IP de la PhYBoX, afin d'éviter que la connexion à la PhYBoX soit aussi rediriger vers le Proxy

Type d'adresse MAC :   adresse de la tablette (plutôt que "aléatoire" qui ne permet pas d'identifier quelle tablette se connecte sur la BoX)


Laissez les autres paramètres sur leur valeur par défaut.


4) Configuration du PROXY de la PhYBoX :

Dans la troisième colonne du panneau de configuration, vous pouvez maintenant activer la protection Internet, c'est à dire autoriser uniquement les sites indiqués dans la liste :

Ajoute un nouveau Site

Lorsque la protection est activée, tous les sites sont interdits, même le moteur de recherche par défaut de votre navigateur. Mais vous pouvez autoriser de nouveaux sites avec le bouton ㊉, en indiquant un mot clé qui se trouve dans l'adresse du site :

Autoriser l'usage du moteur de recherche de Google :   

https://www.google.fr/webhp    ->    mot clé : google

Autoriser le site Wikipedia :   

https://fr.wikipedia.org    ->    mot clé :   wikipedia

Pour supprimer un site, il suffit de double cliquer dessus.


5) Configuration du PROXY de l'Établissement :

Le Proxy de la BoX ne fait que rajouter un filtrage supplémentaire et renvoie les requêtes vers le Proxy de votre établissement. La BoX a donc besoin de connaitre l'adresse de ce Proxy, tout comme elle est déjà configurée sur les équipements informatiques qui sont mis à votre disposition dans votre salle.

Dans la PhYBoX, cette adresse a été mise par défaut sur la valeur usuelle 172.16.0.1 : 3128, mais si ce n'est pas celle de votre établissement, il faudra l'indiquer dans la première colonne du panneau de configuration, avec le paramètre PROXY :


Remarque :

Le Proxy n'est pas activé par défaut pour vous permettre d'essayer la Phybox à la maison où il n'y en a pas. Par contre, pour un usage en classe, il faudra penser à l'activer si vous voulez bénéficier d'un accès à Internet sur les Tablettes.
