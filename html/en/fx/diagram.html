Diagram


The PhYBoX integrates the application : Excalidraw

This application allows you to simply create flowcharts and diagrams, with a library of objects adapted to scientific schematization (symbols of dipoles in Electricity and glassware in Chemistry), which can be easily completed according to your needs.

Tutorial : Tutorials


You can add your own objects to the Library to adapt it to your discipline, by clicking on this object to bring up a menu and validate the “Add to library” option. You can even replace it completely, for example by downloading one of the Thematic Libraries offered on the Excalidraw website : Libraries

The Library files will be taken into account the next time the application is launched, after having deposited them in the following folder :

[phybox]  ->  [web]  ->  [app]  ->  [production]  ->  [diagram]  ->  [excalidraw]  ->  [library]


Note :

The diagram is saved in image format (png), but also includes vector data allowing you to reopen your project later to continue it. You can also save the project in an application-specific format (.excalidraw) which opens directly in Excalidraw when you want to resume your work.
