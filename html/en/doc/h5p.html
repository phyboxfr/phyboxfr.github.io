H5P


The structure of the PhYBoX allows it to naturally host H5P activities : H5P

H5P is an online platform for creating interactive and fun content for education. Very easy to use and requiring not any technical knowledge, it makes activities more dynamic for students, with more than 50 animation models that adapt to all educational situations.

H5P is also available as a desktop application through the version offered by : Lumi H5P

After completing your H5P activity with the Lumi app, in the same way as you would on the H5P website, it is possible to export it into a single HTML file containing all the resources needed for its operation, including images :

This HTML file can then be simply placed in the BoX with the other documents intended for the class. When the student clicks on it, the activity opens in the document viewer, also benefiting from the BoX's Speech Synthesis to verbalize the questions if necessary.
