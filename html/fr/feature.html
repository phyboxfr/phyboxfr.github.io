Fonctions

La Box est Multilingue :

Dans l'espoir que cette application puisse se rendre utile au plus grand nombre, il est possible de choisir la langue dans laquelle la PhYBoX s'exprime, même si sa langue maternelle restera le Français.

La version initiale est disponible en quatre langues (Allemand, Anglais, Espagnol, Français), en remerciant les collègues des disciplines concernées qui ont bien voulu apporter leurs compétences à la traduction de cette application.

Pour la suite, une rubrique dédiée dans le forum permet aux utilisateurs de proposer une traduction dans leur langue pour l'y ajouter. Les fichiers de langue se trouvent dans le dossier suivant :

[phybox]  ->  [web]  ->  [local]  ->  [lang]


Tranquilité du Travail dans un Réseau Local :

Les différentes fonctionnalités proposées par la PhYBoX sont indépendantes d'internet et tournent en autonomie sur l'ordinateur de l'enseignant, dans le réseau local créé par le routeur au sein de la classe.

L'objectif étant que l'essentiel des ressources soit disponibles dans la classe, sans avoir le besoin de passer par le réseau de l'établissement ou d'internet. Il n'y a donc par exemple aucun souci à se faire le jour où la connexion internet de l'établissement est coupée, pour une raison ou une autre.

Cela permet également à l'enseignant de travailler en toute sérénité, sachant que les élèves ont uniquement accès aux documents qu'il a sélectionnés et sans avoir à s'inquiéter des distractions qu'ils pourraient rencontrer en naviguant librement sur internet.

Il est ainsi possible de consulter Wikipedia et d'autres contenus du même type, qui sont stockés directement sur l'ordinateur, sans avoir besoin de passer par internet.

L'usage de sites internet peut donc alors être limité à quelques sites pédagogiques indispensables, pour lesquels il n'aurait pas été possible de trouver un contenu équivalent dans un fonctionnement en local.

Pour cela, la PhYBoX propose son propre système de filtrage des connexions internet, qui permet d'autoriser uniquement les sites que vous aurez choisis, tous les autres étant bloqués par défaut. Consultez la section Admin -> Internet, pour une description détaillée de cette fonctionnalité.


Autonomie, Différenciation et Adaptations :

L'un des aspects principaux de ce genre de dispositif est de faciliter la mise en place d'activités où les élèves travaillent en autonomie, en permettant la différenciation et en proposant des adaptations pour les besoins spécifiques de chaque élève.

Tout d'abord, en disposant différentes versions des documents, avec des niveaux de lecture et de compréhension variés, on laisse la possibilité à l'élève de s'investir à sa mesure dans le travail proposé, en choisissant lui-même ceux qui lui conviennent le mieux. Ceci, plutôt que d'avoir à imprimer différentes versions sur papier.

Cela permet également de mettre des documents supplémentaires facultatifs dans un dossier à part, pour les élèves les plus investis qui auraient le temps d'approfondir encore davantage ce travail.

Par ailleurs, afin de faciliter l'usage pour les élèves rencontrant quelques soucis avec l'écrit, la PhYBoX utilise la synthèse et la reconnaissance vocale intégrées dans le navigateur. Une partie du travail proposé aux élèves peut ainsi être transmis et réalisé à l'oral plutôt qu'à l'écrit.

La PhYBoX est ainsi structurée de sorte que le point de départ du travail des élèves peut être une fiche d'activité au format pdf où sont présentées les consignes. Le lecteur pdf permet en effet un certain nombre d'aménagements techniques qui s'intègrent pleinement dans l'esprit selon lequel a été conçue cette box.

L'élève peut déjà ajuster la taille du texte comme il le souhaite pour le rendre plus lisible, avec le geste tactile usuel à deux doigts. Mais si cela n'est pas suffisant, en appuyant simplement sur n'importe quelle phrase, elle sera lue par la synthèse vocale.

De façon plus générale, la présence du bouton que l'on trouve à plusieurs endroits de la BoX, indique que le message affiché peut être lu par la Synthèse Vocale.

D'autre part, quand il est proposé aux élèves d'analyser une image dont une partie contient un texte, ce dernier peut également être sélectionné et lu grâce à un outil de reconnaissance de caractère. Consultez la section Documents -> Image, pour une description détaillée de cette fonction.

Il est également possible de créer un document texte dicté à la voix avec quelques commandes vocales spécifiques. Le document produit est ensuite sauvegardé dans le dossier de l'élève (au format odt ou docx) de façon automatique. Reportez-vous à la section Applications -> Éditeur, pour une description détaillée de cette fonction.


Liens courts :

Les fichiers pdf reconnaissent également un système de liens raccourcis à cliquer pour envoyer l'élève directement sur les documents adéquats, plutôt que d'écrire une longue consigne pour leur dire d'aller à tel endroit, voir tel document.

Ce système permet ainsi de référencer un fichier ou un dossier de la façon la plus simple possible, sans rendre cette gestion de documents trop contraignante pour l'enseignant, mais il faut l'essayer vous-mêmes pour bien en comprendre tout l'intérêt.

Cette fiche d'activité pdf est donc la porte d'accès la plus simple pour les élèves, afin d'éviter qu'ils ne s'égarent parmi les documents que vous avez préparés pour eux. Vous trouverez une description détaillée de cette fonction importante dans la section Documents -> Pdf de ce site, ainsi qu'un exemple d'usage dans le dossier suivant de la box :

[phybox]  ->  [doc]  ->  [6ème]  ->  Example of links.pdf


Identification des Élèves :

La liste des classes avec les noms des élèves est importée dans la BoX depuis un fichier du type classeur au format ods ou xlsx. Les mots de passe des élèves peuvent être générés soit de façon automatique ou lors de leur première connexion, en les prenant dans un liste de mots prédéfinis ou par un tirage aléatoire.

Au cours de la séance, l'enseignant peut également surveiller la liste des élèves connectés sur chaque tablette. Cela permettra par exemple d'identifier quel élève a utilisé quelle tablette à une date donnée.

Toutes les fonctions de gestion des mots de passe sont décrites dans la section Admin -> Mot de passe.


Indexation des Documents :

Afin d'accéder plus rapidement aux documents, la BoX les indexe dans sa base de données. C'est sur ce fonctionnement que sont basés les liens courts et le moteur de recherche. Visitez la section Admin -> Indexation, pour une description détaillée de cette fonction.


Productions des Élèves :

Les productions des élèves sont enregistrées automatiquement dans un dossier à leur nom sur l'ordinateur de l'enseignant. A la fin de la séquence, il n'y a plus qu'à copier le dossier de la classe sur sa clé USB, pour les corriger par la suite.
