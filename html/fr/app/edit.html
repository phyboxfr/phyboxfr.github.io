La PhYBoX intègre l'application : Summernote

Les documents texte (odt, docx) s'ouvrent dans ce traitement de texte simplifié, dans lequel ont été ajoutés des outils spécifiques pour l'enseignement.

Par défaut, ce type de documents s'ouvre en lecture seule dans le lecteur de documents et ne peut donc être modifié. Pour ouvrir le document en édition, dans le lecteur du même nom, il faut utiliser le bouton édite situé en bout de ligne. Une copie de ce fichier est alors créé dans le dossier de l'élève, qu'il pourra ainsi compléter comme il le souhaite, sans modifier le document original de l'enseignant :



Si l'éditeur est lancé depuis la Galerie d'applications, un nouveau document est ouvert en édtion et enregistré dans le dossier de l'élève, avec son nom et un horodatage au moment du dernier enregistrement :




Fonctionnalités :     Sur la barre d'outils se trouvent quelques fonctionnalités additionnelles.

:   Impression du document sur l'imprimante reliée à l'ordinateur de l'enseignant. Pour activer cette fonction, il faut l'autoriser dans le panneau de configuration et activer une fonctionnalité sur votre ordianteur, qui sera détaillée sur le Forum à la demande.

:   Permet de coller dans le document une image créée dans une autre application de la BoX (dessin, schéma, photo, tracker) pour en faire un compte-rendu.

:   Changement de la police de caractère pour la police Dyslexie.

:   Lecture du texte saisi avec la synthèse vocale, pour les élèves rencontrant des soucis de lecture.

:   Saisie vocale avec le moteur de reconnaissance vocale de Chromium pour taper du texte en le dictant. Le clavier de Chrome le propose déjà, mais dans cette version adaptée, des commandes vocales supplémentaires ont été ajoutées pour simplifier la saisie :

stop : arrête la reconnaissance vocale
annuler : annule la dernière saisie
recommencer : refait une saisie
effacer : efface le dernier mot
effacer ligne : efface la dernière ligne
  
ligne : passe à la ligne
paragraphe : crée un nouveau paragraphe
avant : avance d'un mot
après : recule d'un mot
début de ligne : va au début de la ligne
fin de ligne : va à la fin de la ligne
monter : monte d'une ligne
descendre : descend d'une ligne
début de texte : va au début du texte
fin de texte : va à la fin du texte
  
grossir : met le texte en gras
souligner : souligne le texte
italique : met le texte en italique
  
augmenter : zoom sur l'écran
diminuer : dézoom sur l'écran
écran : plein écran
  
lire : Lire le texte
lire ligne : Lire la ligne en cours
lire tout : Lire tout le texte
lire stop : Arrête la synthèse vocale

Remarque :   Sur certains navigateur tel que Chrome, la reconnaissance vocale utilise un service web externe vers lequel votre flux audio est renvoyé Cette fonctionnalité n'est donc pas utilisable en mode hors ligne et peut ne pas répondre à vos critères de confidentialité.



Options :      Le panneau de configuration propose deux paramètres pour l'Éditeur

Impression : autorise les élèves à imprimer le document directement depuis leur tablette (fonction non active au départ, qui nécessite une manipulation de votre part qui sera précisée sur le Forum, celle-ci nécessitant quelques précautions).

Format : Permet de choisir le format d'enrigstrement des documents en odt ou docx, selon le traitement de texte utilisé préférentiellement.



Remarques :

Soulignement :

Le soulignage d'une partie du texte fonctionne dans l'éditeur, mais ne peut pas être enregistré ou relu depuis le Serveur, n'étant pas pris en charge par la conversion odt/docx ⇔ Html. Cette fonction n'est donc pas utilisable pour le moment.

Insérer une image :

Pour insérer dans le document une image copiée depuis une autre application, il ne faut pas utiliser le bouton copier/coller qui va seulement restituer l'encodage de l'image, mais le bouton image -> copier une image :
