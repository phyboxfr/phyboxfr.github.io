Applications


The PhYBoX integrates various applications offering aids, activities and production tools for teaching.

Applications that allow you to produce documents (text, spreadsheet, drawing, diagram, photo, audio, etc.) automatically save the work carried out by the students on the teacher's computer (rather than on the tablet), in a folder in their name.

All student documents are placed in the [Classes] folder, with the file name including the student's name and a timestamp. So there is no longer any need to worry about where students saved their work.


The applications integrated into the PhYBoX are grouped into several categories :


Library :

contains free encyclopedias and dictionaries, stored on the teacher's computer.

Info :

links to videos presenting the work to be done or extracts of news related to the proposed activities, which can be updated regularly. At the start of the sequence, the students get into the habit of watching the news chosen by the teacher.

Activity :

currently contains only a Quiz application.

Science :

offers some applications dedicated to Science.

Production :

applications allowing students to produce their own documents (text, drawing, diagram, spreadsheet, photo).

Média :

specific players for Virtual or Augmented Reality media (images and videos).

Admin :

tools available only on an administrator account to help them in their task.


Addition or Deletion :

The applications are located in the folder :

[phybox]  ->  [web]  ->  [app]

When starting PhYBoX, all applications present in this folder are automatically added to the applications panel. If you wish to remove some of them to adapt this device to your educational use, simply delete its folder or hide it in a subfolder so that it is no longer detected. .

Conversely, you can also add your own applications by creating a folder with the name of your application and adding an image of the same name, accompanied by a text file (.txt) description (take the example of already existing applications).
