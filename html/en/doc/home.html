Documents


In order to offer a consistent experience that does not depend on the applications installed on each tablet, the documents offered to students open directly in the browser with specific applications depending on the file extension, loaded from the PhYBoX server.

It's as if, instead of using software installed on your computer to edit a document, you used an online application on a site dedicated to processing these kinds of documents. You therefore do not need to install different dedicated applications on each tablet to read all types of document, PhYBoX takes care of it for you.

On the other hand, the chosen web applications are open-source, their open code can therefore be modified in order to adapt their interfaces and functionalities to the BoX environment.

The currently recognized formats are :

texte : txt, odt, doc, docx, pdf
html : htm, html, php
tableur : ods, xlsx
diaporama : pptx
image : psd, png, jpeg, webp, gif, svg, bmp, tiff, svg
video : mp4, webm, mkv, flv, avi, mov, mpeg, wmv
audio : mp3, wav, ogg, flac, wma
