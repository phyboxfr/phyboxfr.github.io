Démarrer


Pour démarrer la PhYBoX, allez dans son dossier principal et cliquez sur l'application box.exe :



Windows peut alors afficher un message d'avertissement provenant de sa fonctionnalité de protection « Microsoft Defender SmartScreen » :


Cette protection peut se déclencher au moment du lancement d'une application téléchargée qui est peu connue ou ne dispose pas d'une signature numérique permettant d'en identifier l'éditeur, ce qui est le cas de la PhYBoX.
