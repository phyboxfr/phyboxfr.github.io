Actualités


Cette application permet de proposer en début de séquence des courtes vidéos extraites des actualités ou sur une thématique donnée, afin de contextualiser l'activité à suivre ou faire le lien avec l'actualité dans le domaine étudié :

Les vidéos doivent être placées dans le dossier [news] :

[phybox]  ->  [doc]  ->  [news]

Personnaliser :

Vous pouvez remplacer l'image qui sert d'illustration dans la galerie des applications pour l'adapter à votre usage :

[phybox]  ->  [web]  ->  [app]  ->  [news]  ->  news.png
