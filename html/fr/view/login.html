Identification


   Le panneau d'identification de l'utilisateur, avec l'accès à 2 Lecteurs spécifiques visibles uniquement de l'Administrateur :



   Affiche un QR Code avec les paramètres de connexion au réseau Wifi.

   Ouvre le Panneau de Configuration.

   Ouvre le Lecteur des Connexions.


Remarque :

Après la déconnexion, le nom du dernier utilisateur reste noté sur ce panneau, même après le redémarrage de la Tablette, afin de pouvoir l'identifier rapidement si besoin était.


Personnalisation :

L'image de fond et les avatars peuvent être remplacés en allant dans le dossier :

[phybox]  ->  [web]  ->  [login]  ->  [res]  ->  [image]

Plus technique, le Surnom affiché au-dessus du nom de l'utilisateur, ici Élève, peut être changé dans le fichier de langue (catégorie slide.label) :

[phybox]  ->  [web]  ->  [local]  ->  [lang]  ->  fr.json
