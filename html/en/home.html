Phybox

An Application to Simplify
the use of Tablets


The PhYBoX is an application intended for Education which allows mobile devices to be linked in the same WiFi network within the class, in order to centralize the activities offered to students from the teacher's computer, facilitating the sharing of resources and applications :




Any device with a Wifi connection (laptop, tablet, smartphone) can connect to it from its browser to the IP address of the teacher's computer, which is displayed by the application.

It allows work in class rather than in the computer room, facilitates the use of a mobile tablet class or allows students to use their smartphone.

The PhYBoX was initially developed for teaching Physics by integrating specific applications, but its main features could certainly be useful to other disciplines.


Important Note :

This device is intended only for classroom use on a local network. It must never be made accessible from the internet, as the latter is not optimized for securing its data.
