Galerie     d'images


La PhYBoX intègre une Librairie d'Images « Libres de Droits & Gratuites à Télécharger » proposée par le site : Pixabay

Cette Galerie d'images est disponible dans l'application Quiz afin de trouver rapidement des images pour illustrer les questions posées aux élèves.

Pour pouvoir bénéficier de ce service gratuit, il faut s'enregistrer sur le site de Pixabay afin d'obtenir un identifiant unique appelé API Key, qui autorise l'usage de leur moteur de recherche au sein d'une autre application. Il permet à ce site de faire des statistiques d'usage et de limiter d'éventuels abus dans l'utilisation de leur service :

Pixabay API

Une fois que vous serez enregistré, l'API Key apparaitra dans la section Search Images :

Il faut ensuite recopier cette API Key dans le panneau de configuration de la BoX pour qu'elle puisse l'utiliser :


Lorsque vous êtes en classe, pensez également à activer le Proxy qui se trouve en dessous et vérifiez que son adresse par défaut est bien celle du Proxy de votre établissement, sinon la BoX ne pourra pas communiquer avec ce service :


Remarque :

Les requêtes envoyées vers le site de Pixabay sont effectuées en activant leur option safesearch afin de ne recevoir que des images qui soient adaptées à tous les âges.
