AR


La PhYBoX intègre l'application : AR.js

Cette application permet d'ajouter de la Réalité Augmentée dans vos documents en y insérant des marqueurs qui fonctionnent comme des QRCodes et que l'application sait reconnaitre. Vous en trouverez un exemple en Chimie dans le dossier :

[phybox]  ->  [doc]  ->  [exemples]  ->  [AR]

Une fois que vous avez rédigé un document dans votre traitement de texte avec quelques marqueurs, enregistrez-le avec les autres documents élèves au format .pdf et dans un dossier nommé [AR].

Ainsi, quand l'utilisateur clique sur ce fichier, la PhYBoX ouvre le lecteur de réalité augmentée et allume la webcam. En présentant la version imprimée du document devant la webcam, les marqueurs seront remplacés par les modèles 3D que vous avez choisi.

Dans le dossier [phybox] -> [asset] -> [app] -> [AR] vous trouverez les images de chaque marqueur à insérer dans dans votre traitement de texte. Chaque marqueur est numéroté et c'est ce numéro qui sert à l'identifier pour le remplacer par le modèle 3D qui porte le même numéro.

Vos modèldes 3D doivent être placés dans le dossier du document pdf, dans un sous-dossier du même nom que votre document :

[phybox]  ->  [doc]  ->  [4ème]  ->  [AR]  ->  [nom du fichier pdf]  ->  3.glb

Ainsi, lorsque vous cliquez sur un fichier pdf qui contient des marqueurs AR, la PhYBoX va remplacer chaque marqueur par le modèle 3D du même numéro et qui se trouve dans le dossier du même nom que le document pdf. C'est la méthode qui a été choisie pour associer chaque marqueur avec le bon modèle, afin d'éviter que l'enseignant ait à écrire du code.

Les modèles 3D doivent être au format .glb, mais on trouve facilement des sites gratuits pour convertir un des nombreux formats de modèle 3D (.stl, .3ds, .blender etc.) vers le glb. Le glb est un format pour le web qui a l'avantage d'inclure dans un seul fichier les textures du modèle.

Un site de modèles en 3D gratuits parmi d'autres : Archive3D
