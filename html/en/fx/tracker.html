Tracker


The PHYBoX integrates the application : JsTrack

Adapted for use on a touch screen, this application allows you to break down the movement of an object in a video, in order to identify its trajectory.

With the tablet or smartphone, students can film a moving object or use a video already made to import it into the application. We can then place a marker on the center of the object, which we can follow image by image, in order to characterize its trajectory.


Main Features : Manual

Automatic recording of video and trajectory in browser memory. You can resume your work in another session, finding what has already been done.

Video format conversion : JsTrack only accepts videos in mp4, but if it was shot in another format like 3gp, it offers to convert it to mp4.

Saving the image of the trajectory in the student's file and in the clipboard, so that it can be imported into the BoX text editor for analysis.

Export object positions over time into an Excel workbook.


Editing from Explorer :

In the BoX explorer, you can open videos already made directly in JsTrack by clicking on the edite button located at the end of the line. This button is only displayed if the name of the folder containing the videos begins with the symbol @ :


Note :

If the students make the videos themselves, the camera recording mode must first be set to mp4 format in the lowest resolution (no more than 1280x720) and limit the duration of videos to a few seconds, in order to minimize the resources needed to process the video in the application, otherwise it may take more time to load the video, depending on the power and amount of memory of the tablet.
