PHYBOT


Cette application est un agent conversationnel généraliste que les élèves peuvent questionner à tout moment pour les aider dans leur travail :



Elle a été conçue afin de permettre l'usage le plus simple possible de l'IA, sans connaissance préalable pour l'enseignant et les élèves.

Suivant le principe de cette BoX, il n'y a donc aucune application tierce à installer, l'IA est incluse dans la Box dès le départ. Il faut juste télécharger un modèle de langage (Mistral, Llama etc.) lors du premier usage, en suivant les instructions indiquées ci-dessous.


Fonctionnalités :

:     Cette icône active le mode en réponse courte qui demande à l'IA de faire un résumé sans rentrer dans les détails, afin d'éviter qu'elle ne parte dans un long développement.

Question  :    En cliquant sur une question, son intitulé est recopié dans la boite de dialogue, ce qui permet de relancer la question en la reformulant si la première réponse n'était pas satisfaisante.

Réponse  :    En cliquant sur une réponse, elle est lue par la synthèse vocale si cette option a été activée et copiée dans le presse-papier, afin de la mettre dans un autre document.


Remarques :

RGPD :

Dans un cadre scolaire, l'usage d'une IA en ligne pose la question de sa conformité avec la législation française sur le traitement des données personnelles qui lui sont confiées au cours de cette activité.

Cette application tourne uniquement dans le réseau local de la classe, sur l'ordinateur de l'enseignant et n'a pas besoin d'internet pour fonctionner. Aucune donnée n'est transmise à des serveurs externes et n'est archivée. Son usage en classe respecte donc pleinement le RGPD.

CPU plutôt que GPU :

Afin que cette application puisse être utilisée sur la majorité des ordinateurs, même s'ils sont peu puissants et ne disposent pas de carte graphique dédiée, l'IA se sert uniquement du processeur (pas de gestion des unités de calcul de la carte graphique type CUDA).

Cette application n'est donc pas conçue pour la performance, mais la plus grande versatilité, afin de s'adapter à toutes les configurations matérielles rencontrées dans les établissements scolaires.

Les délais de réponse de l'IA peuvent donc être de quelques secondes avec des machines disposant de peu de ressources. Il faudra ainsi demander un peu de patience aux élèves qui sont habitués à l'instantanéité des réponses sur des outils comme chatGPT.


Choix du Modèle :

Le générateur d'IA de PHYBOT (moteur d'inférence) est une application qui va lire les données présentes dans un fichier contenant un Modèle de langage étendu (LLM) afin de prédire la réponse la plus probable à la question posée par l'utilisateur. Ces données sont issues de la compilation d'un grand nombre de sources diverses sur une thématique donnée (livres, presse, articles web etc.) au cours d'un long entrainement.

En raison de la taille de ces fichiers (plusieurs Go), la BoX ne contient pas de Modèle initialement, il faut donc en télécharger un avant de pouvoir utiliser l'IA.

Il existe différents formats de fichier Modèle, mais le moteur d'IA qu'utilise la BoX travaille uniquement avec le format GGUF qui a été optimisé pour augmenter significativement le traitement des données qui s'y trouvent.

Le choix du modèle est très large, dépendant de l'usage souhaité et des ressources matérielles présentes sur l'ordinateur (puissance du processeur, quantité de mémoire vive etc.).

Le modèle doit en effet être entièrement chargé dans la mémoire vive de l'ordinateur (RAM) pour en avoir un accès rapide. Le type de modèle pouvant être utilisé dépend donc notamment de la quantité de mémoire disponible sur votre ordinateur. Les modèles les plus légers (moins performants) font autour de 2Go, les suivants demandent au moins 4Go.

La BoX est initialement configurée pour l'usage de deux modèles généralistes légers :

Le Modèle Mistral 7B Instruct est ainsi recommandé pour générer des contenus généralistes en français. Mais pour les petites configurations informatiques vous pouvez utiliser le Modèle Llama 3.2 3B de META.

En gardant en tête qu'ils ne pourront pas être aussi précis que des outils très performants comme chatGPT, puisqu'il y a un équilibre à trouver entre la puissance de la machine sur laquelle tourne l'IA et la qualité de ses réponses.

On trouve des Modèles utilisables gratuitement par exemple sur le site spécialisé Huggingface (site reconnu et légitime) :

MISTRAL :

Mistral 7B Instruct

La version Q4_K_M a 4Go est recommandée, mais si la génération est trop lente sur votre ordinateur, vous pouvez utiliser la version Q2_K qui fait seulement 2,5 Go.

LLAMA :

Llama 3.2 3B Instruct

Une fois téléchargé, le Modèle choisi doit être placé dans le dossier suivant :

[phybox]  ->  [server]  ->  [ai]  ->  [model]


Démarrage du serveur d'IA :

Sur la console, un bouton permet de démarrer ou d'éteindre le serveur d'IA :

L'IA mobilisant beaucoup de ressources, il est alors recommandé de fermer les autres programmes déjà ouverts sur l'ordinateur, en particulier le navigateur.


Si le Serveur ne démarre pas :

Dans le cas où le bouton IA est bien activé, mais lorsque vous utilisez l'application elle affiche un message d'erreur qui indique que le Serveur n'est pas démarré, il se peut qu'il y ait une mise à jour à faire sur l'une des composantes de Windows de votre ordinateur qui est nécessaire pour faire fonctionner le serveur.

Vous pouvez la télécharger (gratuitement) sur le site de Microsoft :

Microsoft Visual C++ Redistributable x64   (vc_redist.x64.exe)



L'IA est générée par le moteur d'inférence : llama.cpp
