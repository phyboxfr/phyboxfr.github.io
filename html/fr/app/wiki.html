La PhYBoX intègre l'application : Kiwix

Elle permet de parcourir hors ligne les sites d'édition collaborative tel que Wikipedia, basés sur la structure du wiki. Plus besoin de connexion internet, les données sont directement stockées sur l'ordinateur dans un seul fichier (une archive Zim).

Des dossiers sont déjà prévus pour accueillir les archives les plus courantes, mais pour alléger le téléchargement de la PhYBoX, elles n'y sont pas incluses. C'est donc à vous de télécharger ces contenus et de les mettre dans le dossier correspondant, ou d'en créer un nouveau.

Il suffit de télécharger l'archive que vous souhaitez mettre à disposition de vos élèves et de l'enregistrer dans le dossier :

[phybox]  ->  [web]  ->  [app]  ->  [library]  ->  [ma librairie]

Au démarrage de l'application, les archives Zim sont automatiquement reconnues et ajoutées à la liste des applications, dans la catégorie où vous les avez mises. Mais pas obligatoirement dans la Librairie, comme PHET qui se trouve dans la catégorie Science.

Télécharger des contenus sur KiWiX : library.kiwix.org

Pour les sites les plus volumineux tel que Wikipedia, il peut y avoir plusieurs versions proposées qui se limitent à une thématique donnée (Histoire, Mathématiques, Sciences etc.) ou qui n'embarquent pas les images et les vidéos. A vous de choisir la version qui vous sera suffisante, selon la place disponible sur le disque du PC.

Exemples de Contenus pour KiWiX :

Wikipédia, L'encyclopédie libre

Vikidia, L’encyclopédie des 8-13 ans

Wiktionnaire, Le dictionnaire libre et gratuit

Gutenberg, Bibliothèque de livres du domaine public

PHET, Simulations interactives pour les sciences et les maths


Personnaliser :

Dans le dossier de l'archive, se trouve une image qui sert d'illustration pour la galerie d'applications, que vous pouvez remplacer par une autre, afin de l'adapter à votre situation.
