The PhYBoX integrates the application : PhotoSwipe

All image formats open with Photoswipe, in order to find in the browser the fluidity offered by image galleries on touch screens. We move from one image to another by dragging them and zooming in on them with the usual pinch gesture.

In the upper right corner is a small toolbar to add some functionality to it :

   Return to the explorer, to the folder where the images came from.

   Adaptation for students experiencing reading problems, using voice synthesis to speak text contained in an image. A blue frame allows you to select a part of the image where the text is located and by double clicking on it, a character recognition tool reads the text with speech synthesis.

OCR character recognition engine : Tesseract.js
