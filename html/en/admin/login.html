➂   Method 1 :   Generate Passwords using 4 Possibilities

Clear : Clears passwords.
Choice : donne le même mot de passe à tout le monde (pour un usage rapide).
Random : random alphanumeric sequence (length: number of characters).
Dictionary : taken from a list of simple words to remember, which is in the file :

[phybox]  ->  [web]  ->  [login]  ->  [dictionary]

After generating the passwords, you can export the list in pdf format with ➆ to print them and distribute them to each student.


➃   Method 2 :   Generate Passwords on First Login

In this easier to manage mode, there is no need to print and distribute passwords. When students log in to their account for the first time, their password is directly displayed to them.

However, in order to prevent a student from having fun connecting to several accounts to obtain a friend's password during the first session, a tablet can only connect to one account (their own). ), from the 2nd try all connections will be blocked for 1 hour.

Two choices are possible to generate the password :

Dictionary : chosen from a list of predefined words.
Random : random alphanumeric sequence (length: number of characters).

At the time of the first connection, tell the students to leave the password box empty, then follow the instructions to obtain their password and (above all) write it down in their notebook, otherwise you will be good to start all over again ::
