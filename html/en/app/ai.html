PHYBOT


This application is a general-purpose conversational agent that students can question at any time to help them with their work :



It was designed to enable the simplest possible use of AI, requiring no prior knowledge from the teacher or students.

In keeping with the design of this Box, there are no third-party applications to install, the AI ​​is built right in from the start. You simply need to download a language model (Mistral, Llama, etc.) during initial setup by following the instructions below.

Notes :

GDPR :

In a school setting, the use of an online AI raises the question of its compliance with legislation regarding the processing of personal data entrusted to it during this activity.

This application runs solely on the BoX's local network, on the teacher's computer and does not require an internet connection to function. No data is transmitted to external servers or archived. Consequently, its use in the classroom fully complies with GDPR.

CPU instead of GPU :

To ensure this application can run on the majority of computers, even those with low processing power and no dedicated graphics card, the AI ​​relies solely on the CPU (without utilizing GPU-based compute units like CUDA).

This application is therefore not designed for performance, but for maximum versatility, in order to adapt to all hardware configurations found in schools.

AI response times can therefore take a few seconds on machines with limited resources. Students accustomed to the instant responses provided by tools like ChatGPT will thus need to exercise a little patience.


Model Selection :

The PHYBOT AI generator (inference engine) is an application that reads data contained in a file containing a Large Language Model (LLM) to predict the most likely response to a user's question. This data is derived from compiling a vast array of diverse sources on a specific topic (books, the press, web articles etc.) during an extensive training process.

Due to the size of these files (several GB), the BoX does not come with a model pre-installed. You must therefore download one before you can use the AI.

There are various model file formats, but the AI ​​engine used by the BoX works exclusively with the GGUF format, which has been optimized to significantly enhance the processing of the data contained within it.

There is a wide range of models to choose from, depending on the intended use and the computer's hardware resources (processor power, amount of RAM, etc.).

The model must be fully loaded into the computer's RAM to ensure rapid access. Consequently, the type of model that can be used depends largely on the amount of memory available on your computer. The lightest models (which offer lower performance) are around 2 GB in size, while the next tier requires at least 4 GB.

The BoX is initially configured for use with two lightweight, general-purpose models. :

The Mistral 7B Instruct model is therefore recommended for generating general-purpose content. However, for smaller computing setups, you can use Meta's Llama 3.2 3B model.

Bearing in mind that they cannot be as precise as high performance tools like ChatGPT, since a balance must be struck between the processing power of the machine running the AI ​​and the quality of its responses.

Starting the AI ​​server :

On the console, a button allows you to start or shut down the AI ​​server :

Since AI is resource-intensive, it is recommended to close other programs already open on the computer, particularly the web browser.


If the server does not start :

If the AI ​​button is enabled but the application displays an error message stating that the server has not started, a Windows component required for the server to run may need to be updated.

You can download it (for free) from the Microsoft website :

Microsoft Visual C++ Redistributable x64   (vc_redist.x64.exe)
