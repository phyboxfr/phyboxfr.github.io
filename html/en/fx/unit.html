Units


The PhYBoX integrates the application : Unités

Application for converting units of measurement for Sciences.

You can modify the list of physical quantities and units proposed to adapt them to your sequence and your language, by editing the unit.cfg file with notepad :

[phybox]  ->  [web]  ->  [app]  ->  [science]  ->  [unit]  ->  unit.cfg

Short Link :

In a PDF document, you can put a link that opens this application directly in a given unit set. To do this, add to the link the chosen physical quantity (u) and the 2 units of measurement to convert (a and b), in the following form :

app:science/unit/?u=speed&a=m/s&b=km/h

This example opens the application on the conversion of the Speed ​​between the m/s and the km/h.

These names correspond to those contained in the file unit.cfg, so they can be adapted in all languages, by replacing them with their equivalent in that language.
