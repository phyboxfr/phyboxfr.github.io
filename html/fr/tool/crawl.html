Capture


Cette application est un outil pour l'administrateur qui permet de télécharger une page d'un site Web dans un unique fichier contenant tous les éléments nécessaires à sa lecture, dont les images.

Il sera ainsi possible de consulter cette page en local sans avoir besoin d'internet, en se constituant une bibliothèque de documents accessibles en permanence. Cela permet également à la BoX d'y ajouter l'usage de la Synthèse Vocale.

Toutefois la fidélité de la réplique de cette page ne peut être assurée que pour les sites dont la structure reste relativement simple.



La page est enregistrée en conservant son format d'origine dans le dossier :

[phybox]  ->  [doc]  ->  [download]

Une option permet d'enregistrer en même temps les pages secondaires dont les liens sont présents dans ce doument. Ils sont alors regroupés dans un sous-dossier pour plus de simplicité. Ainsi, depuis la page principale, si on clique sur l'un de ces liens, la BoX sait retrouver ces pages.


Capture est basée sur l'application : Obelisk
