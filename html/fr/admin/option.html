Options


Sur l'ordinateur de l'enseignant, allez dans le Panneau de Configuration de la PhYBoX, en cliquant sur la petite roue du panneau d'identification à droite :

Ouvrez le Panneau de Configuration






Paramètres : configure différents paramètres (langue, mot de passe etc.)
Applications : sélectionne les applications qui sont disponibles pour les élèves
Internet : active la protection internet, en autorisant uniquement les sites indiqués

Les paramètres permettent par exemple de changer la Langue de l'interface (si vous souhaitez proposer une traduction pour une autre langue, rendez-vous dans le Forum) :


Et celui-ci permet d'ouvrir tous les documents en plein écran, afin de masquer la barre de navigation et donc d'améliorer le confort de lecture :
