Applications


La PhYBoX intègre diverses applications proposant des aides, des activités et des outils de production pour l'enseignement.

Les applications qui permettent de produire des documents (texte, dessin, schéma, photo, audio..) enregistrent automatiquement les travaux réalisés par les élèves sur l'ordinateur de l'enseignant (plutôt que sur la tablette), dans un dossier à leur nom.

Tous les documents élèves sont placés dans le dossier [Classes], le nom du fichier incluant le nom de l'élève et un horodatage. Il n'y a donc plus à se soucier de savoir où les élèves ont enregistré leurs travaux.


Les appplications intégrées à la PhYBoX sont regoupées en plusieurs catégories :


Librairie :

contient notamment des encyclopédies et des dictionnaires libres, stockés sur l'ordinateur de l'enseignant.

Info :

renvoie vers des vidéos présentant le travail à faire ou des extraits d'actualités en rapport avec les activités proposées, que l'on peut mettre à jour régulièrement. En début de séquence, les élèves prennent l'habitude d'aller regarder ces actualités choisies par l'enseignant.

Activité :

contient pour le moment une seule application de Quiz.

Science :

propose quelques applications dédiées aux Sciences.

Production :

applications permettant aux élèves de produire leurs propres documents (texte, dessin, schéma, tableur, photo).

Média :

lecteurs spécifiques pour les médias en Réalité Virtuelle ou Augmentée (images et vidéos).

Admin :

outils disponibles uniquement sur un compte administrateur pour l'aider dans sa tâche.


Ajout ou suppression :

Les applications se trouvent dans le dossier :

[phybox]  ->  [web]  ->  [app]

Au démarrage de la PhYBoX, toutes les applications présentes dans ce dossier sont ajoutées automatiquement dans le panneau des applications. Si vous souhaitez en enlever certaines pour adapter ce dispositif à votre usage pédagogique, il suffit donc de supprimer son dossier ou de la cacher dans un sous-dossier pour qu'elle ne soit plus détectée.

Inversement, vous pouvez également ajouter vos propres applications en créant un dossier au nom de votre application et y ajouter une image du même nom, accompagnée d'un fichier texte (.txt) de description (prenez exemple sur les applications déjà existantes).
