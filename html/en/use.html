Use

Portability :

The application is portable, so there is no installation required. Simply unzip the file you downloaded and launch the box.exe application located in the main folder.

It must be able to be used on a USB key, but the speeds risk limiting work with media that require more resources (videos).


Reliability :

This device works by launching a server on the teacher's computer. This type of software is a sort of referral station which allows requests for documents requested by the tablets to be directed to the folder where they are located.

The PhYBoX is therefore just a local website, with an intuitive interface which allows students to select the documents and applications they need to do their work.

It is based on the XAMPPdistribution of the Apache Foundation, the reliability of PhYBoX is therefore in fact that of its Apache server. This type of server is one of the most used in the world for designing informational or commercial sites and makes it possible to administer a number of simultaneous connections.

In class, the server therefore has no problem managing around thirty connections, as long as the hardware (computer and router) has sufficient characteristics.

In several years of regular use, no failure has ever occurred when used with classes in real conditions. This device can therefore be used with complete peace of mind, without fear of a connection break or anything that would interfere with the students' work.


Launch :

The technical aspect of this device might at first seem a little complex and hold back those of us who are less digitally oriented. However, it has been developed so that no (or almost no) special knowledge is required to use the main functions, at least no more than for using your smartphone.

Simply launch the application on your computer, like any software, and students can then access the content offered from the browser of their tablet or smartphone, at the address indicated by the application.

The easiest thing is to try it for yourself to see how it is set up and how you could use it in class, in order to offer activities to your students.

However, for more precise use or of certain functionalities (notably Virtual and Augmented Reality), an investment to understand their use further will be necessary in order to benefit from all the available resources.


Appearance :

PhYBoX runs in the browser, but it has been optimized for use on tablets and therefore has the appearance and functionality of a mobile application for ease of use.

Particularly in the systematic use of the full screen to remove browser bars, which would otherwise limit the space available on the screen. As well as support for touch gestures, for example with an intuitive image gallery similar to that of Android systems.



Only Technical Aspect :    the IP address of the BoX

On tablets, to simply access BoX, the browser can add a shortcut to its address on the desktop, which the student can then use like any application.

However, for this shortcut to actually be usable, a setting is necessary in the management of your Router.

In fact, the Router identifies each device that connects to it by assigning it an IP address which allows information to be exchanged with it (such as a postal address). But this address may vary depending on the time and number of connections.

In use it is simpler that the IP address of the BoX always remains the same. Fortunately, most routers offer an address reservation feature, so your computer always keeps the same IP address.

In the management application of your Router (its address is often indicated on a label stuck under the device), you must associate the network identifier of your computer called MAC address, with the IP address that you want for your computer. You will find the MAC ID of your computer on the list of connected devices in the Router management application.

In a local network, IP addresses often start with 192.168. To clearly distinguish it from the tablet addresses, our own device is at the address 192.168.0.100, but you can choose whichever you want.
