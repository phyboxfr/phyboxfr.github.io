The PhYBoX includes a "Royalty Free & Free to Download" Image Library offered by the site : Pixabay

This Image Gallery is available in the Quiz application, to quickly find images to illustrate the questions asked of students.

To benefit from this free service, you must register on the Pixabay site in order to obtain a unique identifier called API Key, which authorizes the use of their search engine within another application. It allows this site to produce usage statistics and limit possible abuse in the use of their service :

Pixabay API

Once you are registered, the API Key will appear in the Search Images section :


You must then copy this API Key into the BoX configuration panel so that it can use it :


When you are in class, also remember to activate the Proxy located below and check that its default address is that of your school's Proxy, otherwise the BoX will not be able to communicate with this service :


Note :

Requests sent to the Pixabay website are made by activating their safesearch option in order to only receive images that are suitable for all ages.
