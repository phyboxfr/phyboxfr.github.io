Internet   &   Proxy


The Proxy of the BoX:



1) What is a PROXY ? :

In educational establishments, all Internet connections are sent to a central server called Proxy. It is used in particular to filter connection requests, only authorizing access to sites of educational interest, then it is the proxy which makes the requests for you to the requested sites and sends them back to you.

To make this possible, the computer in your room (just like the mobile classes) has certainly been configured by the IT department on which you depend to send its requests to this agent, identified by its address which is usually: IP = 172.16. 0.1 and port = 3128.

If you look in the Windows or Browser settings, by searching with the proxy keyword, you should find the address of your school's Proxy :

Click on Start   ->   Parameters   ->   Network and Internet   ->   Proxy


2) The PhYBoX   PROXY :

One of the guiding principles of this type of BoX is to have students work in a local network, with the security of knowing that students only have access to documents and applications selected by the teacher.

In order to avoid the inevitable distractions that could arise by letting students browse freely, the use of websites must therefore be limited to a few essential educational sites, for which it would not have been possible to find equivalent content while functioning locally.

To enable this mode of operation, the BoX has its own Proxy which filters connections through a list of authorized sites, which you can choose in its configuration panel.

When activated, this filtering is added to that of the school, so that only the sites that you have whitelisted are authorized and all others blocked :



3) Configuring the WIFI Connection :

To be able to use the BoX Proxy, when you connect a Tablet to the Router's Wifi, you must redirect the connection to the BoX Proxy rather than that of the school. It is the BoX which will subsequently be responsible for sending this connection to the Proxy of your school.

For example, for Android tablets, in the WiFi connection settings, you must choose the Proxy settings as follows :



Wifi connection settings   -->   Advanced settings :

Proxy :   manual

Proxy host name :   the IP address of the Phybox (which is marked on the startup console, for example: 192.168.0.100)

Proxy port :   3128

Bypass the proxy for :   the IP address of the PhYBoX, to prevent the connection to the PhYBoX from also being redirected to the Proxy

Type of MAC address :   address of the tablet (rather than "random" which does not identify which tablet is connecting to the BoX)


Leave other settings at their default value.


4) Configuration of the BoX   PROXY :

In the third column of the control panel, you can now activate Internet protection, i.e. only allow the sites indicated in the list :

    Add a new Site

When protection is enabled, all sites are blocked, even your browser's default search engine. But you can authorize new sites with the ㊉ button, by indicating a keyword found in the site address :

5) Configuration of the PROXY of the School :

The BoX Proxy only adds additional filtering and sends requests to your school's Proxy. The BoX therefore needs to know the address of this Proxy, just as it is already configured on the computer equipment available to you in your room.

In PhYBoX, this address has been set by default to the usual value 172.16.0.1 : 3128, but if it is not that of your school, you will need to indicate it in the first column of the configuration panel, with the parameter PROXY :


Note :

The Proxy is not activated by default to allow you to try the Phybox at home where there is none. On the other hand, for use in class, you will need to remember to activate it if you want to benefit from Internet access on the Tablets.
