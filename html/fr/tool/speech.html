Adaptation


La PhYBoX propose l'usage de la Synthèse Vocale afin d'aider les élèves qui pourraient rencontrer certaines difficultés de lecture :

Sur les documents au format txt, odt, html, pdf et toutes les Librairies Kiwix, il suffit de toucher l'un des textes présents sur la page pour que l'ensemble du paragraphe soit lu par la tablette.

Une icône sur le panneau d'identification permet de désactiver cette fonctionnalité pour les élèves pour lesquels elle ne serait pas nécessaire, afin d'éviter qu'elle ne se déclenche inutilement.

Sur les navigateurs compatibles tel que Firefox, la lecture peut également être accompagnée d'une mise en surbrillance du mot lu au fur et à mesure.

Pour les tablettes sous Android, cette fonctionnalité n'est pas disponible avec les navigateurs basés sur le projet Chromium (Chrome, Brave, Opera..) qui ne le permet pas actuellement.

Si cette fonctionnalité peut être utile à vos élèves, il est alors recommandé d'utiliser le navigateur Firefox pour Android qui la propose : Firefox Android
