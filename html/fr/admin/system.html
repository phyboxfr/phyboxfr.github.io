Système


La PhYBoX est structurée en différents modules qui assurent chacune de ses fonctionnalités. Dans le dossier principal se trouvent les 4 dossiers à la base de ce Système :


Server :

dossier principal qui contient les composantes des serveurs de la BoX, de la Librairie et du Tableau Collaboratif

Web :

interface de la BoX et ses applications, constitué des composantes suivantes :


Login : portail et panneau d'identification des élèves par mot de passe
Explorer : explorateur de fichiers
Index : moteur d'indexation des documents élèves
Ext : applications nécessaires pour lire les différents format de documents suivant leur extension
App : applications apparaissant dans la galerie d'applications
Proxy : gère le proxy de la BoX, afin de limiter l'accès à Internet uniquement aux sites autorisés par l'enseignant
Tools : outils assurant différentes fonctionnalités générales utilisées par les applications (message, conversion de formats, impression, pdf, ocr, qr code etc.)


Doc :

c'est dans ce dossier que vous pouvez mettre les documents destinés aux élèves qui seront visibles dans l'explorateur. Il est nécessaire d'y créer un dossier pour chaque niveau (CM1, 6ème, 1ère etc.)

Classes :

dossier où se trouve tout ce qui concerne les classes, notamment la liste des élèves avec leur mot de passe et où sont enregistrées toutes leurs productions


Remarque :

La BoX est une application portable, son dossier peut donc être décompressé n'importe où, mais le nom des dossiers qui la contiennent ne doit pas comporter d'accent, sinon le serveur ne pourra pas démarrer :

[ C:\Mon dossier\Phybox ]

✔

[ C:\Mon école\Phybox ]

✖
