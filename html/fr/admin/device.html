Tablette


Après avoir lancé la PhYBoX sur l'ordinateur, vous pouvez maintenant connecter les Tablettes.

Il faut tout d'abord connecter vos appareils sur le Wifi du Routeur, puis aller dans le navigateur en recopiant l'adresse affichée par la console de la PhYBoX.

Pour aller plus vite, la PhYBoX peut générer un QR Code, qui permet à la fois de créer la connexion Wifi et de lancer le navigateur pour aller sur l'Adresse de la PhYBoX, si la version Android de la Tablette l'autorise :

Générez un QR Code pour les élèves




Wifi : Le Nom du Réseau Wifi
Clé : Le Mot de Passe du Réseau Wifi
Lien : L'Adresse de la PhYBoX

Par la suite, afin d'éviter que les élèves doivent également taper l'adresse à chaque fois, vous pouvez mettre un raccourci sur le bureau de chaque tablette. Vous trouverez cette fonctionnalité nommée "Ajouter à l'écran d'accueil" dans le menu du navigateur.

Cependant, cela suppose que l'adresse IP de votre ordinateur reste fixe, il faut donc également faire une réservation d'adresse dans l'application qui permet de gérer votre Routeur. Il n'est pas possible de donner une directive générale à ce sujet, puisque chaque modèle de Routeur est différent, il faudra donc vous reporter à son manuel.


Remarque :

Si vous souhaitez que les élèves puissent également se connecter avec leur smartphone (par exemple pour utliiser un casque VR), il vaut mieux créer un deuxième accès indépendant, les Routeurs proposant souvent la possibilité de lancer un réseau pour les Invités.

Sur ce dernier, vous pourrez choisir un Mot de Passe simple (123..) à communiquer aux élèves et que vous pourrez changer facilement si besoin est, sans avoir à changer le mot de passe du Réseau pour les Tablettes.
