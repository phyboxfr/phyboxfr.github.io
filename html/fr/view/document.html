Activité


La BoX dispose de plusieurs Lecteurs indépendants pour visualiser les différents types de médias numériques (image, vidéo, audio) et éditer les textes au format odt et docx. Mais pour afficher les autres types de documents (pdf, html, classeur, diaporama), elle dispose de 2 Lecteurs spécifiques :

La Fiche d'Activité :

L'un des principes directeurs de cette BoX est d'organiser le travail des élèves en mettant à leur disposition une fiche d'Activité au format pdf. Celle-ci présente les consignes, accompagnées de liens (texte ou image) qui renvoient directement vers les documents d'accompagnements déposés dans le dossier [doc].

Vous trouverez des explications détaillées sur la façon de faire ce genre de documents et des liens sous la forme de raccourcis dans la section de ce site Documents -> Pdf, ainsi que des exemples d'usage dans le dossier de la BoX :

[phybox]  ->  [doc]  ->  [6ème]  ->  Example of links.pdf

Cette fiche d'Activité devant rester ouverte durant toute la séquence pour guider les élèves au cours de leur travail, un Lecteur lui est uniquement dédié :


Le Lecteur de documents :

Tous les autres types de documents s'ouvriront dans ce second Lecteur, au fur et à mesure des choix des élèves. Cependant, comme des documents d'accompagnement peuvent également être au format pdf, il a fallu trouver un moyen de les distinguer de la fiche d'Activité, qui doit rester ouverte en permanence.

Ainsi, un document pdf dont le nom commence par une majuscule sera considéré par la BoX comme une fiche d'Activité et ouverte dans le Lecteur précédent. Tous les autres iront dans ce second lecteur, plus adapté pour afficher les documents d'accompagnement divers (pdf, html, classeur, diaporama) :
