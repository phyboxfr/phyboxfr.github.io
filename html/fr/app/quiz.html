Quiz


La PhYBoX intègre l'application : Quiz

Développée pour la PhYBoX, cette application permet de vérifier que les élèves ont acquis les différents éléments d'une séquence de façon ludique : le succès est garantie !


Un Quiz peut être joué de façon individuelle pour que l'élève puisse s'autoévaluer ou avec toute la classe. Dans ce cas, sur un compte Admin, il faut cliquer sur le bouton jeu pour lancer un serveur sur lequel les tablettes élèves se connectent pour jouer simultanément.


En mode individuel, les scores de chaque élève sont enregistrées et consultables en cliquant sur le bouton stat. En mode collectif, à la fin du Quiz des statistiques sont enregistrés dans un tableur, consultable dans le dossier [Classe] -> [Admin] ou en cliquant sur l'image avec les statistiques en haut à droite.

★ Bonus : Double le score d'une question (en gain ou en perte), mais il ne peut être utilisé qu'une fois.
Mode Fantôme : Le nom n'est pas affiché dans les Scores, pour les élèves qui veulent jouer de façon discrète ou stratégique.

Remarque :

Les élèves peuvent aussi créer leur propre Quiz pour les faire jouer par la Classe. Ils sont alors enregistrés dans le dossier [Quiz] de la classe, mais ils ne peuvent être joués tant que l'enseignant ne les a pas validé.



Mode Jeu :      Pour jouer en mode individuel ou collectif.






Mode Création :      Pour créer un nouveau Quiz ou l'éditer.
