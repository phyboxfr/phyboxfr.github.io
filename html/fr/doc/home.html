Documents


Afin de proposer une expérience homogène qui ne dépend pas des applications installées sur chaque tablette, les documents proposés aux élèves s'ouvrent directement dans le navigateur avec des applications spécifiques selon l'extension du fichier, chargées depuis le serveur de la PhYBoX.

C'est comme si, au lieu d'utiliser un logiciel installé sur votre ordinateur pour éditer un document, vous utilisiez une application en ligne sur un site dédié au traitement de ce genre de documents. Vous n'avez donc pas besoin d'installer sur chaque tablette différentes applications dédiées pour lire tous les types de document, la PhYBoX s'en charge pour vous.

D'autre part, les web-applications choisies sont open-source, leur code ouvert peut donc être modifié afin d'adapter leurs interfaces et fonctionnalités à l'environnement de la PhYBoX.

Les formats reconnus actuellement sont :

texte : txt, odt, doc, docx, pdf
html : htm, html, php
tableur : ods, xlsx
diaporama : pptx
image : psd, png, jpeg, webp, gif, svg, bmp, tiff, svg
video : mp4, webm, mkv, flv, avi, mov, mpeg, wmv
audio : mp3, wav, ogg, flac, wma
