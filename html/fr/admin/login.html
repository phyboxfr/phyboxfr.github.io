➀   Change le Mot de Passe Administrateur et Invité. Le mot de passe Invité permet au professeur de donner un accès provisoire à un élève qui rencontrerait un problème d'identification momentané.

➁   Importe la liste des classes à partir d'un classeur (ods, xlsx). Voir l'exemple dans le dossier suivant, en plaçant toujours les colonnes dans cet ordre : Niveau, Classe, Nom, Prénom.

[phybox]  ->  [classes]  ->  classes.ods

➂   Méthode 1 :   Génére les Mots de Passe selon 4 Possibilités

Efface : efface les mots de passe.
Choix : donne le même mot de passe à tout le monde (pour un usage rapide).
Aléatoire : suite alphanumérique aléatoire (longueur : nombre de caractères).
Dictionnaire : tiré d'une liste de mots simples à retenir, qui se trouve dans le dossier :

[phybox]  ->  [web]  ->  [login]  ->  [dictionary]

Après avoir généré les mots de passe, vous pouvez en exporter la liste au format pdf avec ➆ pour les imprimer et les distribuer à chaque élève.


➃   Méthode 2 :   Génère les Mots de Passe lors de la 1ère Connexion

Dans ce mode plus simple à gérer, il n'y a pas besoin d'imprimer et de distribuer les mots de passe. Lorsque les élèves se connectent la 1ère fois sur leur compte, leur mot de passe leur est directement affiché.

Cependant, afin d'éviter qu'un élève ne s'amuse à se connecter sur plusieurs comptes pour obtenir le mot de passe d'un camarade lors de la 1ère séance, une tablette ne peut se connecter que sur un seul compte (le sien), à partir du 2ème essai toute connexion sera bloquée pendant 1h.

Deux choix sont possibles pour générer le mot de passe :

Dictionnaire : choisi dans une liste de mots prédéfinis.
Aléatoire : suite alphanumérique aléatoire (longueur : nombre de caractères).

Au moment de la 1ère connexion, dites aux élèves de laisser la case du mot de passe vide, puis de suivre les consignes pour obtenir leur mot de passe et (surtout) de le noter dans leur carnet, sinon vous serez bon pour tout recommencer à la séance suivante :

Ne rien mettre

➄   Ajoute un nouvel élève qui vient d'arriver dans l'établissement. Son mot de passe sera généré suivant les choix du ➂.

➅   Change ou récupère le mot de passe d'un élève qui l'aurait oublié. Le nouveau mot de passe est généré suivant les choix du ➂.

➆   Imprime la liste des mots de passe à distribuer aux élèves, si on a fait le choix de les générer soi-même.
