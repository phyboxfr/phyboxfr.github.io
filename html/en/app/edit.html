Word    Processor


The PhYBoX integrates the application : Summernote

Text documents (odt, docx) are opened with this simplified word processor, to which tools specific to teaching have been added.

By default, this type of document opens as read-only in the document reader and therefore cannot be modified. To open the document for editing, in the reader of the same name, you must use the edit button located at the end of the line. A copy of this file is then created in the student's file, which they can complete as they wish, without modifying the teacher's original document :



If the editor is launched from the Application Gallery, a new document is opened for editing and saved in the student's folder, with its name and a timestamp at the time of the last save :




Features :     On the toolbar are some additional features.

:   Printing of the document on the printer connected to the teacher's computer. To activate this function, you must authorize it in the control panel and activate a functionality on your computer, which will be detailed on the Forum on demand.

:   Allows you to paste an image created in another BoX application (drawing, diagram, photo, tracker) into the document to create a report.

:   Changed the font to the Dyslexie font.

:   Reading text entered with speech synthesis, for students experiencing reading problems.

:   Voice typing with Chromium's recognition engine to type text while dictating it. The Chrome keyboard already offers this, but in this adapted version, additional voice commands have been added to simplify typing :

(For the moment, works only in french)

stop : stops voice recognition
annuler : cancels the last entry
recommencer : re-enter
effacer : delete the last word
effacer ligne : deletes the last line
  
ligne : jump to line
paragraphe : ccreates a new paragraph
avant : advance one word
après : go back one word
début de ligne : goes to start of line
fin de ligne : goes to end of line
monter : go up one line
descendre : go down one line
début de texte : goes to start of text
fin de texte : goes to the end of the text
  
grossir : makes the text bold
souligner : underlines the text
italique : italics the text
  
augmenter : zoom on the screen
diminuer : zoom out on the screen
écran : full screen
  
lire : Read the text
lire ligne : Read the current line
lire tout : Read all text
lire stop : Stops speech synthesis

Note :   On some browsers such as Chrome, speech recognition uses an external web service to which your audio stream is sent. This feature is therefore not usable in offline mode and may not suit to your privacy requirements.



Options :      The control panel offers two settings for the Editor

Printing : allows students to print the document directly from their tablet (function not active initially, which requires manipulation on your part which will be specified on the Forum, this requiring some precautions).

Format : Allows you to choose the document storage format in odt or docx, depending on the word processor preferentially used.



Notes :

Underlining :

Underlining part of the text works in the editor, but cannot be saved or replayed from the Server, not being supported by odt/docx conversion ⇔ Html. This function is therefore not usable at the moment.
