Collaborative     Board


The PhYBoX integrates the application : Etherpad

This Board offers a space for interactive exchanges with a chat to help each other. Rather than calling on each other throughout the class, pupils can ask each other questions, share their ideas, share documents, to move forward together in learning.


The Start Console, which opens when the BoX is launched, gives direct access to the content of the Board messages :


I'm writing a message for the Collaborative Board


Envoie : Replace the message displayed with that of the Console.
Ajoute : Add the Console message after the other messages.
Enlève : Delete the last message from the Board.
Efface : Clear the entire Board (except Chat).

Remarque :

The Chat cannot be deleted, but in the event of inappropriate messages, you can reset the Board to delete all its contents (messages and Chat) by clicking on the Pad button on the Console that will stop the Tableau Server, then just restart it. On the other hand, if you restart the Box, without turning off the Board Server, it will keep all its content.


Options :


➀   If the Board does not open when included in the BoX window, open it in a new tab and validate https mode (as when opening the BoX).

➁   Authorize the use of Chat on the Board.
