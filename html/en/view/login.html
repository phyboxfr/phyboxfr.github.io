   Displays a QR Code with the WiFi network connection parameters.

   Open the Control Panel.

Note :

After disconnection, the name of the last user remains noted on this panel, even after restarting the Tablet, in order to be able to identify it quickly if necessary.


Personalization :

Background image and avatars can be replaced by going to the folder :

[phybox]  ->  [web]  ->  [login]  ->  [res]  ->  [image]

A little more technical, the Nickname displayed above the user name, here Student, can be changed in the language file (catégorie slide.label) :

[phybox]  ->  [web]  ->  [local]  ->  [lang]  ->  fr.json
