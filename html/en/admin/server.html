Server


To start PhYBoX, go to its main folder and double click on the phybox.exe application.

When PhYBoX is launched, the management console opens. It allows you to control the servers of the BoX, the Bookstore and the Collaborative Table, as well as the Indexing of Documents :

Click on the address to go to the PhYBoX
I'm writing a message for the Collaborative Board


Server Management :
Box : Launches the Box server
Wiki : Launches the Library server
Pad : Starts the Collaborative Board server or stops it, deleting all its content (messages and chat)
Reset : Erase then redo the indexing of documents
Update : Updates document indexing

Collaborative Board :
Send : Replaces the displayed message
Add : Add the message
Delete : Delete the last message
Clear : Clear the entire Board

Note :

Server buttons change to bold when they are started. The next time BoX starts, the servers will launch automatically if you close the window without stopping them first.

If you add a new library (zim archive), you must restart the Library server for it to be taken into account, by clicking twice on the Wiki button.

If the Server don't start :

In case the boot console launches fine, but when you go to the browser it displays an error message stating that it cannot connect to the BoX, there may be a setting to be made on your firewall or there may be a missing component of Windows on your computer that is necessary to run the server.

You can download it (for free) from the Microsoft website :

Microsoft Visual C++ Redistributable 2015-2022 x64
